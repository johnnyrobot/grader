# P4 — Documents & Citations

**Goal:** read anything a student submits (including handwriting), verify their sources, and write
feedback back *into* their files.
**Status:** 🟡 **In progress.** All four P4 modules built:
- `engine/grader/parse.py` — Docling document parser (PDF/DOCX/PPTX/XLSX/HTML/images → markdown)
- `engine/grader/handwriting.py` — Apple Vision + grader-vision transcription (transcribe, then grade)
- `engine/grader/writeback.py` — python-docx/pypdf/openpyxl annotated feedback (never mutates original)
- `engine/grader/citations.py` — 4-layer verification ladder (L0 DOI → L0 Crossref → L1 search → L2 fetch → L3 claim check)
- `engine/verify_citations.py` — scoring harness: 20/29 (69%) accuracy, **zero false positives**
- API endpoints: `/api/parse`, `/api/transcribe`, `/api/citations/verify`, `/api/citations/verify-batch`, `/api/writeback/annotate`, `/api/writeback/report`

**Citation score:** 69% accuracy, 0% false positive rate. Remaining failures require
institutional access (paywalled full-text fetch) or JS rendering. L0 (DOI resolution +
metadata comparison) is at 100% for verified and metadata_mismatch verdicts.
**Parallelizable with P3.**

## A. Document READ

**Stack (licensing-driven — see RESEARCH.md §4):**
- **Docling (MIT)** + **Granite-Docling-258M** (Apache 2.0, has an official **MLX build**) →
  DocTags → Markdown/JSON. Handles PDF, DOCX, PPTX, XLSX, HTML, images, LaTeX. 97.9% table accuracy.
- ⛔ **marker is BANNED** — GPL-3.0 code + OpenRAIL weights with a $2M revenue ceiling.
- ⛔ **PyMuPDF is BANNED** — AGPL (or $10k–50k/yr). Use **pypdf (BSD)**.

**Handwriting (the hard part):**
- **Apple Vision** (`VNRecognizeTextRequest`, via `ocrmac`) first pass — free, on-device, strong on
  print, **unproven on messy cursive**.
- **TrOCR** (IAM-pretrained) or **Kraken v5** as fallback for cursive.
- **And hand the page image directly to the grading VLM** — arXiv 2606.11477 found VLMs hit 98.4%
  on handwritten exam answers vs 88–91% for detector pipelines, *because* they read in context.
- **Transcription must be editable before grading**, with low-OCR-confidence regions flagged
  visually. Never silently grade a bad transcription.
- Scanned work defaults to the **REVIEW_FIRST** lane.

**⚠️ No public benchmark exists for real student handwriting.** Validate on your own 50-page set.
Best public fixture: **Mendeley `sf3kvjwknt/1`** (CC BY 4.0) — 50 digitized exams with scanned
handwriting + *teacher-annotated* PDFs + item-level human marks + answer key. One dataset that
exercises handwriting, rubric, grading, and annotated write-back together.

## C. Citation verification

**The design inverts the obvious one.** Naive: search → crawl → LLM. But most citations in student
work are *academic*, and free keyless metadata APIs settle "does this exist and match?" in **one
HTTP call** — no browser, no search quota. ~10× less cost, latency, and failure surface.

```
L0 RESOLVE (kills ~90% of academic refs — no crawl, no search)
   DOI?      -> doi.org content negotiation -> citeproc-JSON
   Bib string? -> Crossref /works?query.bibliographic=... &mailto=<APP address, never a teacher's>
   Enrich    -> Semantic Scholar (keyless) -> OpenAlex (free key; DOI lookups free)
L1 SEARCH (non-academic only: news, blogs, .gov)
   ddgs (keyless, backoff+cache) | optional user key: Serper/Brave/Tavily
L2 FETCH
   httpx + trafilatura (static) | crawl4ai LIBRARY-ONLY -> Playwright chromium --only-shell (JS)
   *** NEVER run crawl4ai's Docker server — the 2026 RCE/SSRF/auth-bypass CVEs are all in it ***
L3 CLAIM CHECK (fully local)
   Local LLM compares the student's claim against the fetched text. Never leaves the machine.
```

**Retraction check is orthogonal** — a retracted paper resolves *cleanly* with matching metadata, so
the ladder passes it. Cross-check **Retraction Watch** (free CSV, Crossref) or you will silently
bless retracted science.

## The fixtures (already built)

`fixtures/citations/` — 29 fixtures generated from **real Crossref works, deliberately corrupted**.
`python generate_fixtures.py` regenerates.

| Verdict | n | The point |
|---|---|---|
| `verified` | 9 | 6 clean + 3 **real retracted papers** |
| `metadata_mismatch` | 7 | wrong year/author/journal + **DOI resolves to a *different real* paper** |
| `not_found` | 6 | fabricated title on a real author · **unregistered-but-well-formed DOI** |
| `claim_unsupported` | 3 | source real and correctly cited — the *claim* isn't in it |
| `unreachable` | 4 | paywalled · dead host · JS-only |

**The four that actually hurt:** the DOI-to-a-different-paper (every field looks valid alone) ·
the unregistered DOI (defeats regex-shape validation) · `claim_unsupported` (the metadata ladder
is *useless* — this is what justifies L2/L3 existing) · and **`unreachable` vs `not_found`**, because
calling a real-but-paywalled source "fabricated" is the most damaging false positive an academic-
integrity tool can make.

**Score the FP direction separately.** Accusing a student of fabricating a real citation is far
worse than missing a fake one.
