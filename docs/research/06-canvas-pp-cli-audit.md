# canvas-pp-cli — Capability Summary (for Grader app synthesis)

## What it is
- Single self-contained Go 1.26 static binary (~27 MB) at /Users/laccd/code/canvas-pp-cli/canvas-pp-cli. Cobra CLI, auto-generated by "CLI Printing Press" from a Canvas OpenAPI spec — wraps the full Canvas REST API (~1,180 commands) plus hand-authored commands.
- Sibling MCP server binary `canvas-pp-mcp` (cmd/canvas-pp-mcp/main.go) mirrors every CLI command as an agent tool. Also distributable as `.mcpb` bundle.

## Grading-relevant commands (internal/cli/)
- Courses/assignments/roster: `courses index`, `assignments index/show`, `enrollments index`, `roster <course_id>` (joined enrollments+sections+scores+missing work).
- Submissions read: `submissions index <course> <assignment>` (--include submission_comments,rubric_assessment,assignment; --grouped), `submissions show`, `show-anonymous`, `for-students`, `gradeable-students` (SpeedGrader-style), `to-grade [--all-my-courses]` (cross-course ungraded queue), `at-risk`, `since`, `standings`.
- Rubrics: `rubrics index/show/create/update`; submissions include rubric_assessment.
- Grade writes: `submissions update <course> <assignment> <user>` — --submission-posted-grade, --submission-excuse, --submission-late-policy-status, --rubric-assessment, comment flags, --stdin for full JSON. `submissions bulk-update <course>` — batch grade_data[<student_id>][posted_grade|excuse|rubric_assessment|text_comment|file_ids].
- Comments: via submissions update/bulk-update (--comment-text-comment, --comment-file-ids, media); `submission-comments` edits/deletes + uploads comment file attachments.
- Also: moderated-grading, peer-reviews, custom-gradebook-columns, gradebook-history, grade-change-log, late-policy, grading-periods, grading-standards, what-if-grades, assignment-extensions.

## Auth/config
- CANVAS_API_TOKEN (or CANVAS_ACCESS_TOKEN; OAuth2 supported), CANVAS_BASE_URL (default canvas.instructure.com). TOML config.toml + separate credentials.toml (0600). Precedence env > file. `auth`, `doctor`, `profile` commands.

## Scriptability (key for desktop app)
- Global flags: --json, --csv, --plain, --quiet, --compact, --select. `--agent` = --json --compact --no-input --no-color --yes (recommended programmatic mode).
- Non-TTY stdout → auto JSON. Mutations return envelope {action, resource, path, status, success, data, partial_failure?}. Classified exit codes.
- Two integration paths: (a) shell out with --agent and parse JSON; (b) spawn canvas-pp-mcp and call over MCP.
- Local SQLite mirror: --data-source auto|live|local, --max-age, `sync --resources courses,enrollments,users,submissions`. roster/at-risk empty until synced.

## Key gap
- NO built-in submission-file byte download. It returns attachment metadata/URLs only (`submissions show` → attachments[].url; `files public-url <id>`). The Grader app must HTTP GET those URLs itself with Bearer token.
- File uploads (annotated feedback) supported via Canvas 3-step upload: `submission-comments ... create-file` / `files create`, then --comment-file-ids.
